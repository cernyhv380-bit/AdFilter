# AdFilter

Клиентский Fabric-мод для фильтрации рекламных сообщений и обработки отдельных элементов HUD на поддерживаемых серверах.

## Версии Minecraft

| Minecraft | Java | Fabric Loader | Fabric API | Проект |
|---|---:|---:|---:|---|
| 26.3 | 25 | 0.19.5 | 0.164.0+26.3 | `versions/26.3` |
| 1.21.11 | 21 | 0.18.1 | 0.141.6+1.21.11 | `versions/1.21.11` |
| 1.21.4 | 21 | 0.16.14 | 0.119.4+1.21.4 | `versions/1.21.4` |
| 1.20.1 | 17 | 0.16.14 | 0.92.12+1.20.1 | `versions/1.20.1` |

Каждая версия — отдельный Gradle-проект со своим wrapper и настройками зависимостей.

## Сборка

Установите соответствующую версию JDK, перейдите в каталог нужной версии и выполните:

```powershell
.\gradlew.bat clean remapJar
```

Готовые JAR-файлы из текущих сборок находятся в [`release-assets`](release-assets/).
Исходники и конфигурация сборки лежат в каталоге `versions/<версия Minecraft>/`.
